# Diamond Labs — questions about the new prescription form

Two kinds of question, and none of them need a technical answer.

**Part 1 — is this how you want it mapped?** Whether a doctor's choice turns
into the right product. Most are already agreed (41 of them), so only the
unclear ones are here.

**Part 2 — is this what you want to happen?** Whether the form behaves the way
you want as a doctor fills it in. It used to show every question to every
doctor; it now hides ones that don't apply. Those changes are listed so you can
catch any that are wrong.

Anything you confirm is recorded against that exact choice, so you won't be
asked again.

# Part 2 — Is this what you want to happen?

The prescription used to show every question to every doctor, whether it applied
or not. It now hides questions that don't apply. **Each of these is a change a
doctor will notice** — please say if any is wrong.

- **Before:** the drawing pad was always on screen, even for doctors who never intended to draw.
- **Now:** it appears when they tick "I'd like to design (draw) my appliance".

Applies in all three orthodontic sections.
